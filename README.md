# Strategy Lab: professional technical methodology (Monte Carlo edition)

## Upload to Overleaf

1. From the Overleaf dashboard, choose **New Project > Upload Project**.
2. Upload the accompanying `Strategy_Lab_Monte_Carlo_Overleaf_Project.zip` archive (do not paste the zip as text).
3. `main.tex` is the main document. Open `body.tex` to edit the technical content.
4. Use the default **pdfLaTeX** compiler. XeLaTeX is also supported.
5. Click **Recompile**. The table of contents and references are generated automatically.

## Contents
- `main.tex`: paper design, preamble, cover, executive overview and table of contents.
- `body.tex`: complete, editable methodology (19 numbered sections, including 13 Monte Carlo subsections).
- `source_updated.md`: the user-supplied updated documentation (source of technical claims).
- `README.md`: these instructions.

The report's claims, benchmarks, test counts and model performance numbers are drawn from the supplied documentation. This editing task does **not** independently review the code or reproduce its numerical tests. The report describes a research / education prototype, not a live pricing, trading or regulatory system.
